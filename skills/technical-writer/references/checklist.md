# Checklist de Documentación por Tipo de Entregable

## API nueva
- [ ] OpenAPI spec actualizada (o creada si no existía)
- [ ] README actualizado con nuevo endpoint
- [ ] Postman collection actualizada
- [ ] CHANGELOG.md entrada en [Unreleased]
- [ ] JSDoc/XML docs en el código
- [ ] Variables de entorno nuevas en `.env.example`

## Feature nueva
- [ ] ADR si hubo decisión arquitectónica relevante
- [ ] PR description explica el "why" claramente
- [ ] README actualizado si cambia el comportamiento externo
- [ ] CHANGELOG.md entrada

## Proyecto nuevo
- [ ] README completo (todos los bloques del template)
- [ ] `.env.example` con todas las variables
- [ ] `CONTRIBUTING.md`
- [ ] PR template y issue templates en `.github/`
- [ ] `CLAUDE.md` con stack, comandos y convenciones
- [ ] OpenAPI spec desde el primer endpoint
